# 跨领域事实核验

这是一套按事实适用范围工作的核验方法，不是领域分类表。只核验会改变访谈或最终提示词的事实。

## 1. 建立情境假设

从用户的话和材料中暂定：行动或决定、用途与受众、相关实体或制度、地域、日期或版本，以及出错后果。保留歧义，不静默选择解释。陌生性来自缺乏证据支持的关键术语、规则、程序、版本或适用条件，不来自某个领域标签。

## 2. 通过重要性门槛

仅当一项事实可能改变风险分流、范围、适用地区、所需输入、术语、提问顺序、来源要求或验收标准，且它具有专业性、时效性、争议性或超出当前可靠知识时，才研究。研究深度随潜在后果提高。

以下内容不研究：

- 只有用户知道的目标、偏好、风险取舍、私有情境或未公开事实；
- 不影响边界和验收的措辞、脑暴、审美或常识性背景；
- 已有当前、适用且足够的一手来源支持的事实，除非风险或冲突要求交叉核验；
- 只为显得专业、借机回答原问题，或会延误紧急求助的内容。

## 3. 逐项记录证据

先把待核验内容写成一个可检验主张，再寻找拥有或直接产出该规则、规范、记录、数据或发现的来源。搜索摘要、AI 回答、镜像和二手解读只用于发现原始来源。对每个重要主张记录：

```text
主张：一个可检验命题
实质影响：错误时会改变什么
状态：已核实 | 暂定 | 未核实 | 有冲突
证据：来源主体、标题、章节或页码、链接、必要摘录
适用性：发布日期或生效日、版本状态、地域、受众与范围
评估：直接性、质量、佐证、不确定性与反证
访谈影响：它改变哪个问题、约束或来源要求
```

在来源主体的当前发布渠道核对日期和版本，辨别草案、现行、修订、废止与历史版本。适用地域、受众、例外和生效期属于主张本身，不能越界外推。

来源冲突时比较双方的具体命题、定义、范围、权限、日期、底层证据和利益关系，不以数量投票，也不默认较新者胜出。仍无法消解时标为“有冲突”，把分歧及适用条件带入访谈或下游核验要求。

## 4. 表达不确定性与降级

始终区分用户陈述、来源事实、推断、假设、未知和冲突。说明不确定性的原因、影响哪些判断，以及什么证据能改变结论。工具不可用不等于已核实；记录准确主张、可能的来源主体、所需地域或版本，以及具体获取路径。

继续推进不依赖该事实的分支。只有材料私有、受访问限制、未公开或用户独占时，才请用户提供最小必要材料。公开可获取的事实仍由 Agent 负责；当前工具无法获取时保留待核实状态和取证路径。若缺口控制紧急或不可逆的安全边界，缩小或暂停该分支。

## 5. 停止规则

当每个重要主张都已获得可追溯、当前且适用的证据，或已明确标为“未核实/有冲突”并附核验路径时停止。只把情境假设、证据记录、未决项及其访谈影响带回主流程。

## 方法依据

- NIST AI RMF 1.0：情境、适用规范、知识边界、人类监督以及按风险分配核验投入（[MAP 1.1、MAP 2.2、MANAGE 1.2](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-1.pdf)）。
- NIST AI 600-1：区分事实与推断、表达不确定性、链接原始来源、核查引用，并记录无法测量的风险（[§2.8、MS-2.5-003、MS-1.1-009](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf)）。
- W3C Data on the Web Best Practices：记录来源、版本和变更历史（[BP 5、BP 7、BP 8](https://www.w3.org/TR/dwbp/)）。
- ODNI ICD 203：评估来源质量，区分证据、假设与判断，并保留重要反证和分歧（[§6(e)](https://www.intelligence.gov/assets/documents/Intelligence%20Community%20Directives/ICD_203.pdf)）。
- GAO Government Auditing Standards：证据工作的范围随目标、风险与重要性变化（[Evidence §§8.90–8.95](https://guides.gaoinnovations.gov/yellowbook/2024/evidence.html)）。
